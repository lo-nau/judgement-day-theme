# Judgement Day for Omarchy

A Terminator-inspired theme with warm Skynet tones for [Omarchy](https://omarchy.org/).

![Judgement Day preview](preview.png)

## Install

From a terminal:

```bash
omarchy theme install https://github.com/lo-nau/judgement-day-theme.git
```

Or open the Omarchy menu, select **Install → Theme**, and paste:

```text
https://github.com/lo-nau/judgement-day-theme.git
```

Omarchy will clone and apply the theme automatically.
